# Komga Smart Scan — External Diff Tool (PDF-only)

> External Python tool that pre-computes library diffs for **PDF-only**
> libraries and drives targeted Komga API calls, avoiding the full
> `ScanLibrary` pipeline. Requires one new REST endpoint in Komga to support
> creating series + books from disk paths.

---

## 1. Problem Statement

Komga's `ScanLibrary` is slow for large libraries:

| Phase | Bottleneck |
|---|---|
| Phase 1.6 — Reconcile | `tryRestoreSeries/Books()` reads entire files for hashing. N+1 DB queries. Full library loaded into memory. |
| Phase 2 — Fan-out | `analyzeUnknownAndOutdatedBooks()` scans ALL books, emits thousands of tasks. |
| Task queue drain | AnalyzeBook → RefreshBook → RefreshSeries → AggregateSeries run sequentially per series. |

**Goal:** Externally compute what changed, then call Komga REST API only for those
changes — skipping the monolithic reconcile + fan-out pipeline entirely.

---

## 2. Architecture Overview

```
┌───────────────┐     ┌───────────────┐     ┌───────────────┐
│  Python Tool  │────▶│  Komga REST   │────▶│  PostgreSQL   │
│  (diff+apply) │     │  (new endpoint│     │  (read-only)  │
│               │     │   + existing) │     │               │
└───────┬───────┘     └───────────────┘     └───────────────┘
        │
        │ reads
        ▼
┌───────────────┐
│  Filesystem   │
│  (os.walk)    │
└───────────────┘
```

The Python tool directly reads PostgreSQL to get current DB state (series +
books). It walks the filesystem to get current disk state. The diff is computed
entirely in Python. All mutations go through Komga's REST API — **no DB writes
from Python**.

### New Komga endpoint

One new endpoint needs to be added to Komga to close the "can't create series
from outside" gap:

- **`POST /api/v1/series`** — creates a series with optional book list (books
  that already exist on disk, not imported/copied). Calls
  `seriesLifecycle.createSeries()` + `seriesLifecycle.addBooks()` internally,
  emits proper domain events, creates `MEDIA` rows with `STATUS = OUTDATED`.

All other diff actions (delete, analyze, refresh) use existing endpoints.

### 4.2 Controller method

```kotlin
// Added to SeriesController.kt

@Operation(summary = "Create a new series with optional book registrations")
@PostMapping("v1/series")
@PreAuthorize("hasRole('ADMIN')")
@ResponseStatus(HttpStatus.CREATED)
fun createSeries(
    @Valid @RequestBody dto: SeriesCreationDto,
): SeriesDto {
    val library = libraryRepository.findByIdOrNull(dto.libraryId)
        ?: throw ResponseStatusException(HttpStatus.BAD_REQUEST, "Library not found: ${dto.libraryId}")

    val series = Series(
        name = dto.name,
        url = URL(dto.url),
        fileLastModified = dto.fileLastModified.atZone(ZoneId.of("UTC")).toLocalDateTime(),
        libraryId = library.id,
        oneshot = false,
    )

    val created = seriesLifecycle.createSeries(series)

    if (dto.books.isNotEmpty()) {
        val books = dto.books.map { b ->
            Book(
                name = b.name,
                url = URL(b.url),
                fileLastModified = b.fileLastModified.atZone(ZoneId.of("UTC")).toLocalDateTime(),
                fileSize = b.fileSize,
                fileHash = b.fileHash ?: "",
                seriesId = created.id,
                libraryId = library.id,
            )
        }
        seriesLifecycle.addBooks(created, books)
    }

    return seriesDtoRepository.findByIdOrNull(created.id, null)!!.toDto()
}
```

### 4.3 What happens internally

`seriesLifecycle.createSeries()` does (in one transaction):
1. `INSERT INTO SERIES` — the series record
2. `INSERT INTO SERIES_METADATA` — default metadata
3. `INSERT INTO BOOK_METADATA_AGGREGATION` — empty aggregation row
4. Publishes `DomainEvent.SeriesAdded`

`seriesLifecycle.addBooks()` does (in one transaction):
1. `INSERT INTO BOOK` — all books in batch
2. `INSERT INTO MEDIA` — one row per book (`STATUS = 'UNKNOWN'`)
3. `INSERT INTO BOOK_METADATA` — default metadata per book
4. Publishes `DomainEvent.BookAdded` per book

> **Note:** The new series/books have `MEDIA.STATUS = 'UNKNOWN'`, not
> `OUTDATED`. This means Komga will NOT automatically analyze them. The Python
> script must call `POST /api/v1/books/{id}/analyze` after creation to trigger
> extraction. This is intentional — `OUTDATED` means "was previously READY but
> now changed", while `UNKNOWN` means "never analyzed".

> **No `tryRestore`:** The new endpoint intentionally skips the
> `tryRestoreSeries/tryRestoreBooks` logic. This means metadata/read-progress
> from previously-deleted matching content is NOT restored. If restoration is
> needed, trigger a full `POST /api/v1/libraries/{id}/scan?deep=true` which
> handles it. We can add tryRestore to this endpoint later as an optional
> parameter (`?restore=true`).

import psycopg2
from .config import PG_HOST, PG_PORT, PG_DB, PG_USER, PG_PASSWORD

def _conn():
    return psycopg2.connect(
        host=PG_HOST, port=PG_PORT, dbname=PG_DB,
        user=PG_USER, password=PG_PASSWORD,

def read_libraries() -> list[dict]:
    """Return all libraries with id, name, root."""
    with _conn() as conn, conn.cursor() as cur:
        cur.execute('SELECT "ID", "NAME", "ROOT" FROM "LIBRARY"')
        return [{"id": r[0], "name": r[1], "root": r[2]} for r in cur]

def read_series(library_id: str) -> list[dict]:
    """Return active series for a library, keyed by URL."""
    with _conn() as conn, conn.cursor() as cur:
        cur.execute(
            'SELECT "ID", "NAME", "URL", "FILE_LAST_MODIFIED" '
            'FROM "SERIES" '
            'WHERE "LIBRARY_ID" = %s AND "DELETED_DATE" IS NULL',
            (library_id,),
        )
        return [
            {"id": r[0], "name": r[1], "url": r[2],
             "file_last_modified": r[3].isoformat() if r[3] else None}
            for r in cur
        ]

def read_books(library_id: str) -> list[dict]:
    """Return active books for a library, keyed by URL."""
    with _conn() as conn, conn.cursor() as cur:
        cur.execute(
            'SELECT "ID", "NAME", "URL", "FILE_LAST_MODIFIED", "FILE_SIZE", '
            '"FILE_HASH", "SERIES_ID" '
            'FROM "BOOK" '
            'WHERE "LIBRARY_ID" = %s AND "DELETED_DATE" IS NULL',
            (library_id,),
        )
        return [
            {"id": r[0], "name": r[1], "url": r[2],
             "file_last_modified": r[3].isoformat() if r[3] else None,
             "file_size": r[4], "file_hash": r[5], "series_id": r[6]}
            for r in cur
        ]

### 5.4 `walker.py` — Filesystem walker (PDF only)

```python
from pathlib import Path
from datetime import datetime, timezone

def walk_library(root: str, *, exclusions: set[str] | None = None,
                 oneshots_dir: str | None = None) -> dict:
    """
    Walk a library root directory scanning for .pdf files only.

    Returns:
    {
      "series": {
        "file:///root/SeriesA": {
          "url": "file:///root/SeriesA",
          "name": "SeriesA",
          "file_last_modified": "2026-01-01T00:00:00+00:00",
          "books": [
            {"url": "file:///...", "name": "Ch01", "file_size": 1234,
             "file_last_modified": "..."}
          ]
        }
      },
      "oneshots": [...]   # root-level .pdf files
    }
    """
    root_path = Path(root).resolve()
    exclusions = exclusions or set()

    def _mtime(path: Path) -> str:
        return datetime.fromtimestamp(
            path.stat().st_mtime, tz=timezone.utc
        ).isoformat()

    series = {}
    oneshots = []

    for entry in sorted(root_path.iterdir(), key=lambda e: e.name.lower()):
        if entry.name in exclusions:
            continue

        if entry.is_dir():
            books = []
            for f in sorted(entry.rglob("*"), key=lambda e: e.name.lower()):
                if f.is_file() and f.suffix.lower() == ".pdf":
                    books.append({
                        "url": f.as_uri(),
                        "name": f.stem,
                        "file_size": f.stat().st_size,
                        "file_last_modified": _mtime(f),
                    })
            if books:
                series[entry.as_uri()] = {
                    "url": entry.as_uri(),
                    "name": entry.name,
                    "file_last_modified": _mtime(entry),
                    "books": books,
                }

    # Oneshots at root level (PDF only)
    for entry in sorted(root_path.iterdir(), key=lambda e: e.name.lower()):
        if entry.is_file() and entry.suffix.lower() == ".pdf":
            oneshots.append({
                "url": entry.as_uri(),
                "name": entry.stem,
                "file_size": entry.stat().st_size,
                "file_last_modified": _mtime(entry),
            })

    # Oneshots in dedicated oneshots directory (PDF only)
    if oneshots_dir:
        oneshots_path = root_path / oneshots_dir
        if oneshots_path.is_dir():
            for f in sorted(oneshots_path.iterdir(), key=lambda e: e.name.lower()):
                if f.is_file() and f.suffix.lower() == ".pdf":
                    oneshots.append({
                        "url": f.as_uri(),
                        "name": f.stem,
                        "file_size": f.stat().st_size,
                        "file_last_modified": _mtime(f),
                    })

    return {"series": series, "oneshots": oneshots}
```

### 5.5 `diff.py` — Diff engine

```python
from dataclasses import dataclass, field

@dataclass
class Diff:
    new_series:     list[dict] = field(default_factory=list)
    deleted_series: list[dict] = field(default_factory=list)
    new_books:      list[dict] = field(default_factory=list)
    deleted_books:  list[dict] = field(default_factory=list)
    changed_books:  list[dict] = field(default_factory=list)


def compute(series_from_db: list[dict], books_from_db: list[dict],
            fs_data: dict) -> Diff:
    """Compare DB state vs filesystem state."""

    db_series_by_url = {s["url"]: s for s in series_from_db}
    db_books_by_url  = {b["url"]: b for b in books_from_db}

    fs_series = fs_data["series"]
    fs_books = {}
    for s in fs_series.values():
        for b in s["books"]:
            fs_books[b["url"]] = b
    for oneshot in fs_data.get("oneshots", []):
        fs_books[oneshot["url"]] = oneshot

    db_urls_s = set(db_series_by_url)
    fs_urls_s = set(fs_series)
    db_urls_b = set(db_books_by_url)
    fs_urls_b = set(fs_books)

    diff = Diff()

    # New series
    for url in fs_urls_s - db_urls_s:
        diff.new_series.append(fs_series[url])

    # Deleted series
    for url in db_urls_s - fs_urls_s:
        diff.deleted_series.append(db_series_by_url[url])

    # New books (inside existing series + oneshots that aren't new series)
    new_series_urls = {s["url"] for s in diff.new_series}
    for url in fs_urls_b - db_urls_b:
        # Skip books that belong to new series (handled together)
        parent_series_url = _get_parent_series_url(url, fs_series)
        if parent_series_url in new_series_urls:
            continue
        diff.new_books.append(fs_books[url])

    # Deleted books
    for url in db_urls_b - fs_urls_b:
        diff.deleted_books.append(db_books_by_url[url])

    # Changed books
    for url in db_urls_b & fs_urls_b:
        fs_b = fs_books[url]
        db_b = db_books_by_url[url]
        if (fs_b["file_last_modified"] != db_b["file_last_modified"] or
            fs_b["file_size"] != db_b["file_size"]):
            diff.changed_books.append({**fs_b, "id": db_b["id"], "series_id": db_b.get("series_id")})

    return diff


def _get_parent_series_url(book_url: str, fs_series: dict) -> str | None:
    """Find which series directory contains this book URL."""
    from pathlib import PurePosixPath
    from urllib.parse import unquote, urlparse
    book_path = PurePosixPath(unquote(urlparse(book_url).path))
    for series_url, series_data in fs_series.items():
        series_path = PurePosixPath(unquote(urlparse(series_url).path))
        try:
            book_path.relative_to(series_path)
            return series_url
        except ValueError:
            continue
    return None
```

### 5.6 `api.py` — Komga REST client

```python
import requests
from urllib.parse import urljoin
from .config import KOMGA_URL, KOMGA_USER, KOMGA_PASSWORD, MAX_API_RETRIES

_session = None

def _get_session():
    global _session
    if _session is None:
        _session = requests.Session()
        _session.auth = (KOMGA_USER, KOMGA_PASSWORD)
        _session.headers.update({"Content-Type": "application/json"})
    return _session

def _post(path: str, json_data: dict | None = None, **kwargs):
    s = _get_session()
    url = urljoin(KOMGA_URL, path)
    for attempt in range(1, MAX_API_RETRIES + 1):
        try:
            resp = s.post(url, json=json_data, timeout=300, **kwargs)
            resp.raise_for_status()
            return resp
        except requests.RequestException as e:
            if attempt == MAX_API_RETRIES:
                raise
            print(f"  Retry {attempt}/{MAX_API_RETRIES}: {e}")

def _delete(path: str):
    s = _get_session()
    url = urljoin(KOMGA_URL, path)
    for attempt in range(1, MAX_API_RETRIES + 1):
        try:
            resp = s.delete(url, timeout=120)
            resp.raise_for_status()
            return resp
        except requests.RequestException as e:
            if attempt == MAX_API_RETRIES:
                raise
            print(f"  Retry {attempt}/{MAX_API_RETRIES}: {e}")

def list_libraries() -> list[dict]:
    return _get_session().get(
        urljoin(KOMGA_URL, "/api/v1/libraries")
    ).json()

def create_series(library_id: str, name: str, url: str,
                  file_last_modified: str,
                  books: list[dict]) -> dict:
    """Create series + register its books. Returns the created SeriesDto."""
    return _post("/api/v1/series", {
        "libraryId": library_id,
        "name": name,
        "url": url,
        "fileLastModified": file_last_modified,
        "books": [
            {
                "name": b["name"],
                "url": b["url"],
                "fileSize": b["file_size"],
                "fileLastModified": b["file_last_modified"],
                "fileHash": b.get("file_hash", ""),
            }
            for b in books
        ],
    }).json()

def add_books_to_series(series_id: str, library_id: str,
                        books: list[dict]) -> dict:
    """Register books already on disk into an existing series."""
    return _post(f"/api/v1/series/{series_id}/books", {
        "libraryId": library_id,
        "books": [
            {
                "name": b["name"],
                "url": b["url"],
                "fileSize": b["file_size"],
                "fileLastModified": b["file_last_modified"],
                "fileHash": b.get("file_hash", ""),
            }
            for b in books
        ],
    }).json()

def delete_book(book_id: str):
    _delete(f"/api/v1/books/{book_id}/file")

def delete_series(series_id: str):
    _delete(f"/api/v1/series/{series_id}/file")

def empty_trash(library_id: str):
    _post(f"/api/v1/libraries/{library_id}/empty-trash")

def analyze_book(book_id: str):
    _post(f"/api/v1/books/{book_id}/analyze")

def refresh_book_metadata(book_id: str):
    _post(f"/api/v1/books/{book_id}/metadata/refresh")

def refresh_series_metadata(series_id: str):
    _post(f"/api/v1/series/{series_id}/metadata/refresh")
```

### 5.7 `applier.py` — Orchestrator

```python
from .diff import Diff
from . import api
from .config import DRY_RUN, BATCH_SIZE
from collections import defaultdict

def apply(diff: Diff, library_id: str, fs_data: dict):
    """Apply diff results to Komga via API calls."""

    # ── Step 1: Create new series + their books ───────────
    for s in diff.new_series:
        print(f"  + Creating series: {s['name']}")
        if not DRY_RUN:
            created = api.create_series(
                library_id=library_id,
                name=s["name"],
                url=s["url"],
                file_last_modified=s["file_last_modified"],
                books=s["books"],
            )
            # Analyze + refresh each new book
            for b_id in _extract_book_ids(created):
                api.analyze_book(b_id)
                api.refresh_book_metadata(b_id)

    # ── Step 2: Add new books to existing series ──────────
    # Group new books by their parent series
    books_by_parent = defaultdict(list)
    for b in diff.new_books:
        parent_url = _get_parent_series_url(b["url"], fs_data["series"])
        if parent_url:
            books_by_parent[parent_url].append(b)

    # We need series_id for each parent. Query DB or use
    # the diff context to resolve series URL → series ID.
    for parent_url, books in books_by_parent.items():
        series_id = _resolve_series_id(parent_url)
        if series_id:
            print(f"  + Adding {len(books)} books to series {parent_url}")
            if not DRY_RUN:
                api.add_books_to_series(series_id, library_id, books)
                for b_id in _extract_book_ids_from_response(books):
                    api.analyze_book(b_id)
                    api.refresh_book_metadata(b_id)

    # ── Step 3: Delete removed books ──────────────────────
    for b in diff.deleted_books:
        print(f"  - Deleting book: {b['name']}")
        if not DRY_RUN:
            api.delete_book(b["id"])

    # ── Step 4: Delete removed series ─────────────────────
    for s in diff.deleted_series:
        print(f"  - Deleting series: {s['name']}")
        if not DRY_RUN:
            api.delete_series(s["id"])

    if diff.deleted_books or diff.deleted_series:
        print("  Emptying trash...")
        if not DRY_RUN:
            api.empty_trash(library_id)

    # ── Step 5: Analyze + refresh changed books ───────────
    for i, b in enumerate(diff.changed_books):
        print(f"  ~ Analyzing + refreshing: {b['name']} ({i+1}/{len(diff.changed_books)})")
        if not DRY_RUN:
            api.analyze_book(b["id"])
            api.refresh_book_metadata(b["id"])

    # ── Step 6: Refresh series metadata for affected series
    affected_series_ids = set()
    for b in diff.changed_books:
        if b.get("series_id"):
            affected_series_ids.add(b["series_id"])
    for sid in affected_series_ids:
        print(f"  ~ Refreshing series metadata: {sid}")
        if not DRY_RUN:
            api.refresh_series_metadata(sid)
```

### 5.8 `main.py` — CLI entry point

```python
#!/usr/bin/env python3
"""Komga Smart Scanner CLI."""

import sys
from . import config, db, walker, diff, applier, api

def main():
    libs = api.list_libraries()
    if not libs:
        print("No libraries found.")
        sys.exit(1)

    print("Libraries:")
    for i, lib in enumerate(libs):
        print(f"  [{i}] {lib['name']}  (id={lib['id']})")

    try:
        choice = int(input("Select library: "))
    except (ValueError, IndexError):
        print("Invalid selection.")
        sys.exit(1)

    lib = libs[choice]
    lid = lib["id"]
    root = lib.get("root", "").replace("file://", "")

    # 1. Read DB state
    print(f"\nReading DB state for library '{lib['name']}'...")
    db_series = db.read_series(lid)
    db_books = db.read_books(lid)
    print(f"  DB: {len(db_series)} series, {len(db_books)} books")

    # 2. Walk filesystem
    print("Walking filesystem...")
    fs = walker.walk_library(root)
    fs_series_count = len(fs["series"])
    fs_books_count = sum(len(s["books"]) for s in fs["series"].values()) + len(fs["oneshots"])
    print(f"  FS: {fs_series_count} series, {fs_books_count} books")

    # 3. Diff
    d = diff.compute(db_series, db_books, fs)
    print(f"\n── Diff ──")
    print(f"  New series:      {len(d.new_series)}")
    print(f"  Deleted series:  {len(d.deleted_series)}")
    print(f"  New books:       {len(d.new_books)}")
    print(f"  Deleted books:   {len(d.deleted_books)}")
    print(f"  Changed books:   {len(d.changed_books)}")

    total_actions = (len(d.new_series) + len(d.deleted_series) +
                     len(d.new_books) + len(d.deleted_books) +
                     len(d.changed_books))

    if total_actions == 0:
        print("\n✓ No changes detected. Library is up to date.")
        return

    if config.DRY_RUN:
        print("\n[DRY RUN] No changes applied.")
        return

    confirm = input(f"\nApply {total_actions} changes? [y/N] ")
    if confirm.lower() != "y":
        print("Aborted.")
        return

    # 4. Apply
    print("\n── Applying ──")
    applier.apply(d, lid, fs)

    print("\n✓ Done.")

if __name__ == "__main__":
    main()
```

## 6. Diff Detection Matrix

| Category | Detection | Mapped API Action |
|---|---|---|
| **New series** | Dir URL in FS, not in DB (active) | `POST /api/v1/series` → analyze books |
| **New books in existing series** | Book URL in FS but not in DB, parent series exists | `POST /api/v1/series/{id}/books` → analyze |
| **Deleted series** | Series URL in DB active, not in FS | `DELETE /api/v1/series/{id}/file` |
| **Deleted books** | Book URL in DB active, not in FS | `DELETE /api/v1/books/{id}/file` |
| **Changed books** | Same URL, different mtime/size | `POST /api/v1/books/{id}/analyze` + `/metadata/refresh` |
| **Unchanged** | Same URL, same mtime, same size | No action |

## 7. Time-Saving Estimation

| Library size | Full ScanLibrary | Smart scanner (Python + API) |
|---|---|---|
| 1,000 books / 100 series | ~30s–2min | ~3–15s |
| 10,000 books / 1,000 series | ~5–30min | ~15s–2min |
| 100,000 books / 10,000 series | ~1–10h+ | ~1–10min |
| 100K on NFS | 10–30h+ | ~2–15min |

**Why it's faster:**
- No in-memory loading of entire library (DB read is streaming to Python)
- No `tryRestoreSeries/Books()` file hashing on scan
- No Phase 2 fan-out query (`analyzeUnknownAndOutdatedBooks` over all books)
- Targeted analyze/refresh only for books that actually changed
- Filesystem walk is single-pass `os.scandir`/`Path.iterdir()` (fast on any FS)

**Caveat:** The Post-scan task queue (AnalyzeBook executing the actual comic
parsing) still runs, but only for actually changed/new books. For a library
with 100K books where only 50 changed, that's 50 analyze tasks instead of 100K.
